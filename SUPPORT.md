# Getting help

- **Questions and ideas**: use [GitHub Discussions](https://github.com/Lets-Decode-AI/FlowLocal/discussions).
- **Bugs**: open an [issue](https://github.com/Lets-Decode-AI/FlowLocal/issues/new/choose) with your OS, FlowLocal version, model and reproduction steps.
- **Feature or model requests**: use the matching issue template.
- **Security problems**: do not post publicly; follow [SECURITY.md](SECURITY.md).

Please search existing issues and discussions first.
